## 口径（与任务书逐条对应）

- bin：`floor(全局帧号 × bins / totalFrames)`；不整除时向左侧取整、**不丢尾帧**。
- 不跳采样：每帧先把多声道 `|sample|` 取最大折叠成单帧峰值，再归 bin；峰值钳 [0,1]。
- rms：`sqrt(Σ 单帧峰值² / bin 内帧数)`（内层均值平方根，作用在折叠后的峰值上）。
- 流式硬约定：按帧顺序逐帧累加 ⟹ 任意块大小与整段 **逐位相等**（`memcmp` 验证，非近似）。
- bins 钳 [16,4096]、默认 512；`totalFrames=0` 返回全零、不崩；sampleRate 未知 ⟹ `durationSec=0`。

关键判据实测值：

- 30 s / 48 kHz / 立体声，10.0 s 唯一满幅脉冲、其余 −60 dBFS，bins=300：
  argmax bin = **100**（∈ [99,101]），`peaks[100] = 1.000000`，`maxPeak = 1.000000`，
  `durationSec = 30.0`；
- 1024 帧分块（1407 次 `addBlock`）vs 整段：`peaks` / `rms` `memcmp` 逐位相等；
  另测块长 1 / 37 / 1024 / 4800 / 65536，均与整段逐位相等；
- bins 钳位：0/1/15 → 16，16/300/512/4095/4096 原样，4097/100000 → 4096，缺省 512；
- `totalFrames=0`：peaks/rms 仍 300 项且全 0、maxPeak=0、durationSec=0，不崩；
- 满幅多声道取 `abs max`（不是相加），>1 钳到 1.0、NaN→0、±inf→1.0；
- 0.8 正弦：128/128 个 bin 的 rms/peak ∈ [0.7054, 0.7088]（0.707 ± 0.02 判据内）。
