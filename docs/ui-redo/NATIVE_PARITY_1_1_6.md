# 1.1.6 → 1.1.7 原生 AppKit 移植对照

判据：以 1.1.6 已发布界面的**用户可见能力**为清单（来源：`src/net/ui_page.h`、`src/net/ui_script.h` 的
`S.view` 分支与设置分组），逐项给出原生落点与状态。状态只有三种：
**已实现**（有真实数据/动作，构建与自检通过）、**部分**（入口在、能力不完整）、**未实现**（原生没有）。
本文不把"计划"写成"已实现"。
